# Data

This directory contains the datasets used by the Content Tagging & Competency Mapping (CTCM) project.

## Data Availability

Some of the original project materials used during development, testing, benchmarking, and evaluation are **not included in this public repository** due to confidentiality and non-disclosure agreement (NDA) requirements.

Only materials that are permitted to be publicly shared are included in this directory.

## Public Dataset

The following dataset is included because it is publicly available:

```text
hrsd_data_ai_taxonomy.csv
```

This dataset is not part of the confidential bootcamp materials.

## Confidential Materials

Other learning-content files and evaluation materials used during the project are intentionally excluded from this public repository in accordance with the applicable confidentiality and NDA requirements.

These materials were used during the development and evaluation of the project but are not distributed through this repository.

## Note

The absence of certain input and evaluation files from this directory is intentional and does not indicate that they were not used during the project.

For the complete project architecture, implementation, deployment, benchmarking methodology, and results, please refer to the main project README.
